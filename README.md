# Diabetic-Retinopathy-Detection-and-Classification-using-Deep-Learning
Diabetic Retinopathy (DR) is a leading cause of blindness, and early detection is vital. This project uses a fine‑tuned Inception v3 model on retinal fundus images with preprocessing and augmentation to balance data. Results show accurate classification of DR severity, supporting large‑scale screening and early diagnosis.
Diabetic Retinopathy (DR) is a vision-threatening complication of diabetes and one of the leading causes of blindness worldwide. Early detection is critical to prevent irreversible damage, but manual screening is labor-intensive and subject to variability. This project proposes an automated, machine learning-based approach for accurate detection and classification of DR severity using retinal fundus images.
The system architecture begins with image retrieval and preprocessing steps such as data cleaning, normalization, and augmentation to handle class imbalance and improve generalization. Data augmentation techniques like rotation, flipping, resizing, and color jitter are applied to underrepresented classes, while oversampled classes are down-sampled to maintain uniformity across categories.
The processed dataset is split into training and validation sets, and a deep convolutional neural network, Inception v3, pre-trained on ImageNet, is fine-tuned for DR classification. The model is optimized using a weighted cross-entropy loss function to address class imbalance, and trained with the AdamW optimizer and a learning rate scheduler for efficient convergence. Model performance is evaluated using a wide range of metrics including accuracy, precision, recall, F1-score, specificity, false positive rate (FPR), false negative rate (FNR), mean squared error (MSE), and Area Under the Curve (AUC).
Experimental results demonstrate the model's effectiveness in accurately predicting DR severity levels ranging from 0 (No DR) to 4 (Proliferative DR), showcasing the potential of deep learning and machine learning techniques in supporting early diagnosis and large-scale diabetic eye screening programs.
